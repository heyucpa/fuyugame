# 測試

在有 Playwright（`NODE_PATH=$(npm root -g)`）和 Chromium 的環境用 node 跑。

| 檔案 | 檢查什麼 |
|---|---|
| `run_driver.sh` | 跑根目錄的 `house_driver.js`（上百項功能檢查）。有 8 項是「預期值過時」（跑步名次、圖鑑項目數、公告圖示、漫畫格子、備份欄位、休息密碼等），不是遊戲壞掉，之後有空再對齊 |
| `compat.js` | 從歷史上 12 個舊版本各存一份進度，用現在的版本讀，鈴錢、家具、寵物、名字都不能變（先用 `git show <commit>:house.html > tests/old/v_<commit>.html` 備好舊版） |
| `inv_safe.js` | 收到邀請碼、去朋友家玩、回家：存檔前後比對，只能多一個 `myHouse_invites` |
| `inv_fuzz.js` | 400 張亂改過的邀請卡＋壞掉的連結：不能當掉、不能污染、不能改到自己的進度 |
| `roundtrip.js` | 有新功能的存檔連續重新載入 3 次，進度不變 |
| `ghost_twice.js` | 找小幽靈一天兩隻、第三隻不會出現、關掉再開也有第二隻、隔天重來 |
| `island.js` | 小島地圖：房子位置不在水裡、路都通、點房子自動走進去、鍵盤、搖樹、認識動物朋友 |
| `economy.js` | 每天第一場小遊戲雙倍（只一次）、獎盃可以賣（要確認、價格固定、不會再發第二座） |
| `english.js` | 英文單字：每週的字、聽音選圖、看圖拼字、獎金算對 |
| `foodmenu.js` | 吃東西／餵食選單：變小藥水排在最下面（印出順序，肉眼看） |
| `noselect.js` | 畫畫板：拖到旁邊、連點旁邊的字都不會反白；整個視窗鎖定、關掉就解除；備份框還能選字 |
| `touchdraw.js` | 用手指（觸控）畫：還是畫得出來、拖到畫布外面不會選到字 |
| `allowance.js` | 零用錢：每週一次不累積、可關、新存檔不會一開始就送、壞存檔修好、爸媽會來送 |
| `fuzz.js` | 亂按：隨機點畫面、按鍵、開分頁、開關小島、玩小遊戲，300 步，電腦＋手機各一次，不能有 JS 錯誤、存檔要讀得回來（會自己點到「強制更新」重新載入的不算） |
| `invitemail.js` | 邀請卡：Email 按鈕、iPad 在 Safari 打開連結會提醒回小屋 App 貼上、在 App 裡或電腦直接收下 |
| `duck.js` | 英文單字：背景音樂暫時靜音、關掉視窗就恢復（不改設定） |
| `letters.js` | 字母找找看（b d p q）：認識→描寫→找找看→複習整套走完、亂畫不會過關、獎金、記錄練了幾次 |
| `islandfun.js` | 小島上的小趣味：南瓜燈每天最多吐 3 顆糖、噴水池、池塘、海鷗、貝殼、動畫會結束、壞存檔修好 |
| `run.js` | 跑步：小卡和小島上的切換、速度約 2.1 倍、記在這台機器（不放存檔）、Shift 暫時跑 |
| `island2.js` | 小島第二階段：日夜四個時段、金幣每天 5 枚走過自動撿、池塘走過去就釣魚、小動物與腳踏車、壞存檔修好 |
| `tools.js` | 小島道具：點海自動拿釣竿走到岸邊、❗時點才釣到、太早不算、沒點會跑掉；網子抓蝴蝶進相簿；鏟子要先拿、挖洞一天 6 樣、同一個洞不能再挖；搖樹蜜蜂：心情飽足掉一點、緊張表情、跑開 |
| `savestress.js` | 存檔／備份／自動讀取壓力測試：亂改 400 次不丟錯且穩定、重新載入 3 次、空間不夠不刪舊存檔、存檔紀錄上限與反悔、備份壞的全擋、還原連結、壞存檔鎖住保留原文、兩個分頁、存檔格開換刪、舊版搬移、亂改存檔開遊戲 |
| `voice.js` | 語音：Win10／Edge／iPad／Chrome／只有大陸腔／沒中文 各種聲音清單都挑對台灣腔、家長選的優先、設定頁和選語音視窗 |
| `tablemusic.js` | 桌上有東西：點桌子跳選單（拿起來換位置／收起來／搬桌子）；音樂選單：開關一顆、每首歌直接選、點外面關掉 |
| `tkdpool.js` | 跆拳道館、游泳池：自動換道服／泳衣、腰帶考試（要練 3 次、考過換顏色、沒過不降級、黑帶最高）、踢板／跟著做動作／打水比賽／潛水撿寶／跳水、小島上的房子 |
| `placefun.js` | 道館、泳池裡每樣東西點了都有事做（打沙包、踢靶、劈木板、鏡子、腰帶架、標語、跳水板、救生員椅、游泳圈、沖水、毛巾、遮陽傘）、對練小遊戲打到 5 分、節奏跆拳道玩完一首、穿道服的同學來問要不要對打、寵物下水狗爬式、游泳圈套上／擦乾拿下 |
| `magic.js` | 神奇魔法藥水：隨機、不會連續一樣、10 種都出得來、收集數、巨人變大、存檔讀回來、壞資料清掉、時間到變回來、小寶寶喝了變別的魔法 |
| `layout.js` | iPad 橫直、手機橫直、超寬螢幕、一般筆電：不能橫向捲動、視窗不能超出畫面 |
