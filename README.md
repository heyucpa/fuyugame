## apartment.html — 公寓大廈記帳

管委會用的收支流水帳，單一 HTML 檔，用瀏覽器打開就能用，不需安裝也不需連網。
資料存在瀏覽器的 localStorage，請定期到「設定與備份」匯出 JSON 備份檔。

- 記帳：收入／支出流水帳，可依年度、月份、科目、帳戶、關鍵字篩選
- 月報表：上月結轉、科目別小計與本年累計、月底結餘、各帳戶餘額，可列印或存成 PDF
- 年度彙總：科目 × 12 個月的收支對照表，含每月結餘與期末結餘
- 設定：社區名稱、資金帳戶與期初餘額、會計科目自訂、備份匯出與匯入
- 匯出：流水帳／月報表／年度彙總皆可存成 CSV（含 BOM，Excel 直接開不會亂碼）
